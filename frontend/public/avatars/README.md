# Author Avatars Directory

This directory is intended to store author profile images for the picluxe blog.

## Required Images

For the blog to display correctly, you need to add the following avatar images:

- `avatar-1.jpg` through `avatar-6.jpg` (square images, minimum 200x200px)

## Avatar Guidelines

- Use square images (1:1 aspect ratio)
- Minimum resolution of 200x200 pixels (higher is better for retina displays)
- Crop images to focus on the face
- Consistent style across all avatars (e.g., similar lighting, background, framing)
- Compress images for web without significant quality loss

## Placeholder Avatars

During development, you can use placeholder avatar services like:

- [UI Faces](https://uifaces.co/) - AI-generated faces for UI mockups
- [Random User Generator](https://randomuser.me/) - API for generating random user data including avatars
- [Lorem Picsum](https://picsum.photos/) - Random images that can be used as avatars

Example usage with Lorem Picsum:
- `https://picsum.photos/200/200?random=1`

## Production Avatars

For production, replace these placeholder avatars with:
- Real author photos
- Professional headshots
- Branded avatars that match your company's identity

## Privacy Considerations

When using real people's photos:
- Ensure you have permission to use their likeness
- Consider privacy implications
- Provide alt text for accessibility
